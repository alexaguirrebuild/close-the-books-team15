# Guion de la demo

Unos 80 segundos con el conjunto con golden: `npm run dev` y abre `/?demo=train&autoload=1`. Todo se hace con el teclado salvo donde se indica. Los datos son inventados; para enseñar los reales, elige la carpeta raíz y la fase Sample.

Para repetirla desde cero, borra los datos del sitio en el navegador: las decisiones se guardan entre recargas.

| Tiempo | Qué hacer | Qué decir |
| --- | --- | --- |
| 0:00 | Resumen, sin tocar nada | «Tesorería recibe 200.000 movimientos en un semestre. El pipeline propone; las personas revisan lo que importa. Aquí se ve cuánto queda y qué hacer ahora». |
| 0:12 | Señalar la tabla «Dónde se pierden movimientos» | «La misma puntuación que el servidor, comprobada cifra a cifra, y en qué tipo de caso falla el pipeline». |
| 0:22 | `Enter` para entrar en Revisión | «Lista y caso juntos. La cola no va por importe: la nota cuenta líneas y pares, así que ordena por lo que más puede subirla». |
| 0:32 | `V` hasta Con excepción; moverse con `J` hasta un caso con dos partidas | «El por qué de cada propuesta, de un vistazo. Y una barra: es el movimiento, y se cierra cuando las partidas cuadran». |
| 0:42 | `Tab`, escribir un importe menor, `Esc` | «Si no cuadra, lo dice en palabras». |
| 0:47 | `E`, elegir Corto por descuento | «Elijo la excepción y el importe se ajusta solo a la política: un descuento aceptado liquida la factura entera». |
| 0:55 | `Enter`, y luego `Z` | «Confirmar es una tecla; deshacer, otra». |
| 1:02 | `V` hasta Listas; `Shift`+`C`; `Enter` | «Lo que tiene confianza alta se confirma en lote, viendo antes qué lleva». |
| 1:10 | Clic en un segmento desde Resumen (`Alt`+`1`) | «Y un segmento abre justo esos errores, con lo que esperaba el golden. Es como afinamos el pipeline». |
| 1:18 | `Alt`+`3` | «Comprueba el formato con las reglas del servidor, y nunca bloquea lo que el servidor acepta. El envío real sale del motor del equipo; Cuadra es donde las personas revisan». |
